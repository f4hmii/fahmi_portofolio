# fahmi_portofolio

Website portofolio personal yang dibangun menggunakan Next.js, Tailwind CSS, dan desain bergaya Neubrutalism.

## Fitur
- Desain Neubrutalism yang interaktif
- Animasi efek mengetik (Typewriter)
- Menampilkan semua daftar project yang pernah dikerjakan
- Responsif di seluruh perangkat (Mobile, Tablet, Desktop)
